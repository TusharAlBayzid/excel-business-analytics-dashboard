# 📊 Executive Business Performance Dashboard (Excel & BI)

An end-to-end Microsoft Excel Business Intelligence project designed to transform raw transaction data into actionable business insights. This project demonstrates data cleaning via **Power Query**, structured **Data Modeling**, custom **DAX Measures**, and an interactive executive **Dashboard** with dynamic slicers.

---

## 🎯 Project Overview

This assignment project focuses on building a dynamic business dashboard to analyze company sales performance across regions, product lines, and timeframes. 

### Key Objectives:
- **Data Integration:** Import and clean raw business sales data.
- **Transformation:** Standardize text, fix date formats, and eliminate structural errors using Power Query.
- **Data Modeling:** Structure data tables and build logical relationships for analytical calculations.
- **DAX Calculations:** Compute key business metrics (Total Sales, Total Quantities, Average Sales per Order).
- **Interactive Visuals:** Design executive charts paired with interactive Slicers for multi-dimensional filtering.

---

## 🛠️ Tools & Technologies Used

- **Microsoft Excel** (Data Analysis & Visualization)
- **Power Query** (ETL - Extract, Transform, Load)
- **Power Pivot & DAX** (Data Modeling & Measures)
- **PivotTables & PivotCharts** (Visual Analytics)
